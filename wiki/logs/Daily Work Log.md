## Logging convention

Each meaningful update uses:

```md
## HH:MM CST — Short title

### Changed
- ...

### Files
- ...

### Verification
- ...

### Decision or note
- ...

### Next
- ...
```

Use the actual local timestamp when the entry is written. If earlier work is reconstructed later, label it as a retrospective summary rather than inventing precise times.
